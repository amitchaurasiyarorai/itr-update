ITR Update

Income Tax e-Filing portal statistics, tracked every day

Why this exists

Every year, crores of Indians file their Income Tax Returns and then wait — sometimes for months — to hear about their refunds. The e-Filing portal publishes headline statistics, but only today's totals. There's no history, so you can't see how fast returns are being processed, whether the backlog is shrinking, or roughly when it might clear.

ITR Update records those numbers every day and shows how they change. Public data should be publicly accessible: presented clearly, updated regularly, and free for everyone.

How it works

  1. Fetched automatically. A small Python script runs twice a day (around 8 AM and 6 PM IST) and reads the public statistics from the Income Tax e-Filing portal.
  2. Stored as open data. Each reading is appended to a CSV file in a public repository — versioned, auditable and free to download.
  3. Visualised on this site. The dashboard reads that CSV directly and draws the charts in your browser. No backend, no database, no tracking.

What's tracked

Registered individual users
Individual taxpayers registered on the e-Filing portal.
Returns filed
ITRs filed for the current assessment year (Aadhaar-linked PAN).
E-verified returns
Filed returns that have been e-verified and entered the processing queue.
Processed returns
Returns the Income Tax Department has finished processing.
Backlog
E-verified minus processed — returns still waiting in the queue.

The portal refreshes these figures roughly once a day, and counts restart with each new assessment year.
